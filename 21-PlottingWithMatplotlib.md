# Plotting Arrays with Matplotlib

If you need to generate a plot for your values, it's very simple with **Matplotlib**.

## Basic Line Plot

For example, you may have an array like this one:

```python
import numpy as np

a = np.array([2, 1, 5, 7, 4, 6, 8, 14, 10, 9, 18, 20, 22])
```

If you already have Matplotlib installed, you can import it with:

```python
import matplotlib.pyplot as plt

# If you're using Jupyter Notebook, you may also want to run the following
# line of code to display your plots in the notebook:
%matplotlib inline
```

All you need to do to plot your values is run:

```python
plt.plot(a)

# If you are running from a command line, you may need to do this:
# plt.show()
```

## Plotting Two 1D Arrays

You can plot a 1D array against another, for example to draw a line and mark the same points with dots:

```python
x = np.linspace(0, 5, 20)
y = np.linspace(0, 10, 20)

plt.plot(x, y, 'purple')  # line
plt.plot(x, y, 'o')       # dots
```

`np.linspace(start, stop, num)` generates `num` evenly spaced values between `start` and `stop` — a convenient way to build the x-axis values for a plot.

## More Advanced Visualizations

With Matplotlib, you have access to an enormous number of visualization options — for example, a 3D surface plot:

```python
fig = plt.figure()
ax = fig.add_subplot(projection='3d')

X = np.arange(-5, 5, 0.15)
Y = np.arange(-5, 5, 0.15)
X, Y = np.meshgrid(X, Y)
R = np.sqrt(X**2 + Y**2)
Z = np.sin(R)

ax.plot_surface(X, Y, Z, rstride=1, cstride=1, cmap='viridis')
```

`np.meshgrid()` takes two 1D coordinate arrays and produces the 2D coordinate grids needed to evaluate a function over a plane — a common pattern for surface and contour plots.

To read more about Matplotlib and what it can do, take a look at the [official Matplotlib documentation](https://matplotlib.org/stable/index.html). For installation instructions, see the [official installation guide](https://matplotlib.org/stable/users/installing/index.html).

## 📝 Study Notes

- **`plt.plot()` needs 1D-like inputs.** If you accidentally pass a `(N, 1)` array instead of a flat `(N,)` array, Matplotlib usually still plots it correctly, but it's a common source of confusing shape-mismatch errors in more complex plotting calls — flatten with `.ravel()` if you hit one.
- **`np.linspace` vs `np.arange` for plotting:** `linspace(start, stop, num)` guarantees exactly `num` evenly spaced points *including* both endpoints — ideal for smooth curves. `arange(start, stop, step)` is defined by step size instead, and due to floating-point rounding can sometimes include or exclude the endpoint unpredictably. Prefer `linspace` for plotting.
- **Remember to call `plt.show()`** when running as a `.py` script from the terminal (not needed in Jupyter with `%matplotlib inline`) — otherwise no window appears and the script just exits silently.

**Try it yourself:**
1. Plot `y = x**2` for `x` ranging smoothly from -10 to 10 using `np.linspace`.
2. Compare the number of points generated by `np.linspace(0, 1, 5)` vs. `np.arange(0, 1, 0.25)` — are they the same?
